VR-Based Hand Rehabilitation Glove

A flex-sensor glove that tracks finger movement in real time and turns it into gamified VR exercises for post-stroke hand therapy.

Harshada Kale·EE399·Guide: Dr. Uttama Lahiri·November 2024
  • Arduino
  • Flex sensors
  • Python
  • Vizard (VR)
  • Serial communication
View project on GitHub ↗

Why a glove?

Recovering hand function after a stroke takes intensive, repetitive exercise, and that repetition is exactly what makes traditional therapy demotivating. When exercises feel like chores, patients stop doing them. This project asks whether a low-cost wearable and a game can make the same movements more engaging.

I built a glove with five flex sensors, one per finger, that measures finger flexion in real time. The readings drive a hand model inside a VR environment, where the patient performs interactive exercises with immediate visual and audio feedback.

Sensing finger bend

A flex sensor is a resistor whose resistance rises as it bends. Straight, each of mine sits at roughly 25 kΩ. Every sensor is wired as a voltage divider with a 39 kΩ resistor, so bending a finger changes the voltage on an analog pin of the Arduino Uno. The Uno's 10-bit ADC turns that into a number between 0 and 1023, and the firmware sends all five values as one comma-separated line over serial every 100 ms. 

int flexSensorPins[] = {A0, A1, A2, A3, A4};
int flexSensorValues[5];

void loop() {
  for (int i = 0; i < 5; i++)
    flexSensorValues[i] = analogRead(flexSensorPins[i]);

  for (int i = 0; i < 5; i++) {
    Serial.print(flexSensorValues[i]);
    if (i < 4) Serial.print(",");
  }
  Serial.println();
  delay(100);
}

Calibrating to each patient

Raw sensor values mean little on their own, and every hand has a different range of motion. To choose a sensible full-bend angle, I measured how far the fingers curl into a fist on 3–4 people with an angle-measuring app. The result was consistently around 60°, so the model maps a flat hand to 0° and a closed fist to −60°.

Each session starts with a two-step calibration. First the patient holds the hand flat so the baseline value of every sensor is recorded. Then they make a fist so the maximum bend is recorded. After that, each finger's reading is linearly mapped between its own baseline and maximum, which adapts the VR hand to that patient's range of motion. 

def map_value(value, in_min, in_max, out_min, out_max):
    return out_min + (out_max - out_min) * (value - in_min) / (in_max - in_min)

angle = map_value(flex_values[i], baseline[i], max_bend[i], 0, -60)

The VR environment

The VR side is written in Python with Vizard. It loads a rigged hand model, reads the serial stream, and updates the finger joints ten times a second. Background music and sound effects make the exercises feel more like a game than a therapy drill.

Exercises

Balloon pop

The patient bends the index to pinky fingers to inflate a virtual balloon in steps, with an air sound at each step. When the thumb bends past a set angle, the balloon pops with a sound effect. The task encourages coordinated finger flexion and gives a clear reward for completing it. This exercise is implemented and working.

Musical fingers

In the second exercise, the patient touches the thumb to each finger in turn, and every successful touch plays a different note. It trains finger opposition and fine motor control, which matter a lot after a stroke. This one is still in progress. The thumb has several joints that a single flex sensor cannot capture, so I manually adjusted the thumb joint angles in the model and compared them against sensor values to find a mapping. That calibration is not finished. One alternative I planned is adding another flex sensor on the palm to improve tracking.

Limitations

  • Sensor drift. Accuracy degrades over prolonged use.
  • Limited tracking. Only finger flexion is measured, with no wrist or hand orientation.
  • Recalibration. Sensors shift with repeated use, so the system needs recalibrating regularly.

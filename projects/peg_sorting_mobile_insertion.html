Peg Sorting & Mobile Peg Insertion

Robotic manipulation coursework covering vision-guided peg sorting and precise insertion on a vertical board using a mobile manipulator.

Overview

This coursework explores two increasingly challenging manipulation tasks: sorting four differently shaped pegs into matching sockets, followed by inserting pegs into sockets on a vertical board using a mobile manipulator. Both tasks combine perception and motion planning, with the second adding the complexity of coordinating a mobile base with an arm.

Peg sorting

The first task uses color and shape perception to identify square, triangular, circular, and hexagonal pegs and associate each object with its matching socket. The manipulation pipeline connects image-based detection with forward and inverse kinematics, path planning, and trajectory generation so the robot can approach, grasp, transport, and place each peg.

Mobile peg insertion

The second task extends the setup to a mobile manipulator and an upright board with standard- and tight-fit sockets. The system must estimate the board pose, detect peg colors and 3D poses, determine in-plane orientation, and pair each peg with its target sockets. Workspace analysis and motion planning help position the robot for insertion, while tighter clearances make alignment and contact-aware execution more demanding.

Core robotics concepts

  • Perception: color and shape detection for identifying pegs and sockets.
  • Kinematics: forward and inverse kinematics to map target poses to robot configurations.
  • Planning: collision-aware paths and trajectories between grasp, transfer, and insertion poses.
  • Mobile manipulation: coordinating base positioning and arm reach for a vertical work surface.

Key challenge: the task moves beyond picking an object in open space. Accurate pose estimation, approach direction, and alignment become critical when a peg must fit into a socket—especially on a vertical board or with reduced clearance.

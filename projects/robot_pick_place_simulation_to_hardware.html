Overview

This coursework follows a pick-and-place task from simulation to a physical robot. The simulation stage in MuJoCo provides a controlled environment for testing inverse-kinematics methods, workspace limits, and randomized object placements before moving to hardware execution.

Simulation in MuJoCo

The simulated pipeline begins with an off-the-shelf inverse-kinematics solver and compares it with custom IK approaches. The environment includes a table and randomized scenarios, allowing the manipulation sequence to be tested across different object configurations. Successful demonstrations and failure cases provide a basis for examining reachability, motion planning, and the reliability of the selected IK solution.

Execution on hardware

The hardware task transfers the pick-and-place sequence to a physical manipulator. Control begins with joint-space waypoints and progresses toward Cartesian motion using inverse kinematics. This progression exposes practical differences between simulated motion and real execution, where target accuracy, reachable configurations, and reliable movement between pick and place poses matter.

Key robotics concepts

  • Inverse kinematics: finding joint configurations that place the end effector at a target pose.
  • Workspace analysis: checking whether pick and place poses are reachable.
  • Trajectory planning: generating motion between object pickup and placement.
  • Failure analysis: using randomized scenarios to expose reachability and planning limitations.

Main takeaway: a successful simulated trajectory is only one part of a manipulation system. Comparing IK strategies and then moving to hardware highlights the importance of reachable poses, appropriate control representations, and reliable execution.

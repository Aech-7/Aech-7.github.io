Force-Controlled
Dough Rolling

Developing a Franka-based robotic system that uses force feedback and vision to roll dough toward a more uniform thickness.

ROS2 Franka Force Control Computer Vision

Franka robot performing a dough-rolling pass.

Motivation

Rolling dough to a uniform thickness is difficult because the dough continuously deforms under the applied force. A fixed robot position or a constant force does not necessarily produce the same thickness across the entire surface. Applying too much force can also deform or tear the dough. The goal of this project is to develop a force-controlled robotic system that can roll dough to a uniform thickness while adapting to the changing interaction between the roller and the dough.

Setup

The setup uses a Franka robot arm with a rolling tool attached to its end effector, along with a force/torque sensor to measure the interaction during rolling. A camera is used to locate the dough and determine its boundaries so that the robot can automatically determine the start and end positions of each rolling pass. The complete robot-side system is implemented in ROS2.

Controller

The controller uses a force-control loop on top of a velocity controller. During each pass, the robot rolls across the dough while measuring the interaction and the resulting thickness. The measured profile is then used to adjust the force for subsequent passes, while a potential-field / virtual-wall mechanism provides real-time resistance as the roller approaches the desired thickness.

Current work

An important part of the project is improving how the robot estimates the dough thickness and responds to it. Initially, the end-effector position during contact was used as an estimate of thickness. I am now moving toward direct vision-based thickness measurement. Tests with a top-mounted RealSense showed depth errors of a few centimeters, which is too noisy for the required millimeter-level accuracy. The next setup therefore uses a side-mounted camera to estimate the dough thickness profile, while the control architecture is being extended toward a hybrid force-position controller.

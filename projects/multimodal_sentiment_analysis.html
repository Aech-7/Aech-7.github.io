Smart Labeling & Multimodal Sentiment Analysis

Building a cost-conscious sentiment data pipeline that combines weak supervision, active learning, LLM-assisted labeling, multilingual translation, and synthetic speech validation.

Overview

Sentiment analysis depends not only on the classifier, but also on the quality and coverage of its training data. The project develops a smart labeling pipeline designed to reduce reliance on expensive manual annotation. The next stage explores a broader challenge: how to expand a small sentiment dataset while supporting Hindi text and voice-based reviews, without allowing noisy synthetic data to undermine model quality.

Part I — Smart data labeling

The first stage focused on building labels from multiple sources and understanding how reliable they were. The pipeline combines human annotation with heuristic labeling functions and LLM-assisted labels, with Label Studio supporting the annotation workflow. Fleiss' Kappa was used to reason about agreement between annotators, while Snorkel-style weak supervision combined labeling rules into a larger set of candidate labels.

Active learning is used to prioritize reviews that are most informative to label. Least-confidence and entropy-based sampling identify examples where a model is uncertain, helping direct annotation effort toward ambiguous cases instead of selecting samples at random.

Part II — Expanding and validating the dataset

The extension starts from instructor-provided gold-standard, weakly labeled, and LLM-labeled reviews. A TF-IDF Logistic Regression baseline filters the additional LLM-labeled samples by confidence and agreement with their supplied labels before the datasets are consolidated and deduplicated.

To address class imbalance, Classical augmentation uses WordNet synonym replacement and English-to-Hindi-to-English back-translation, with sentiment-bearing words protected during synonym replacement. Jaccard similarity provides a simple filter for outputs that are either too close to the original or have changed too much. A few-shot LLM prompt generates new synthetic reviews across Positive, Negative, and Neutral classes. The baseline model flags generated reviews whose predicted sentiment disagrees with the requested label.

Hindi translation and sentiment preservation

For multilingual support, a balanced sample of English reviews is translated into Hindi and then back into English. BLEU scores measure lexical similarity between the original and back-translated text, while the sentiment model checks whether the predicted class remains consistent. Manual review of selected translations complements these checks and helps identify recurring translation errors.

Testing the voice-review pipeline

The speech pipeline converts selected reviews into synthetic audio using gTTS and saves them as WAV files. Librosa extracts duration, spectral centroid, zero-crossing rate, and mean MFCC features. The local Whisper tiny model transcribes each recording back to text, and word error rate (WER) measures how much the transcript differs from the source review. Samples with high WER can then be flagged for inspection.

Final evaluation

The final dataset combines consolidated reviews with quality-filtered classical augmentations, unflagged LLM-generated samples, and back-translated English paraphrases. A provided black-box evaluator and frozen PyTorch text embedder are used to compare training on the consolidated base dataset against training on the expanded dataset, with the same gold-standard reviews held out for testing.

Evaluation principle: a larger dataset is not automatically a better dataset. The aim is to test whether added samples contribute useful variation while preserving sentiment labels and avoiding unnecessary noise. The actual performance improvement should be reported from the evaluator's measured results.

Key Takeaways

  • Data quality is a modelling decision. Label agreement, uncertainty, and filtering matter alongside classifier choice.
  • Augmentation needs validation. Similarity and sentiment checks help catch both near-duplicates and meaning-changing rewrites.
  • Multilingual and speech support add new failure modes. Back-translation and speech-to-text round trips provide practical ways to inspect them.
  • Evaluation must be controlled. Comparing base and augmented training sets against the same gold-standard test set gives a clearer view of whether added data helps.

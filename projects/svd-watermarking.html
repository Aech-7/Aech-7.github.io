SVD-Based Image Watermarking

An image watermarking system using Singular Value Decomposition to embed and recover a QR-code watermark, with experiments studying image quality and robustness under Gaussian noise and JPEG compression.

View on GitHub →

Overview

Digital watermarking allows information to be embedded into an image without placing an obvious visible mark on the image.

In this project, a QR code containing a roll number is embedded into RGB cover images using Singular Value Decomposition. The watermark strength is controlled using a parameter α.

The project focuses on the trade-off between image quality, watermark recoverability, and robustness when the watermarked image is degraded.

MAIN QUESTION

How strong should the watermark be so that it remains recoverable without unnecessarily degrading the image?

The SVD Approach

For a cover image C, Singular Value Decomposition gives:

C = UCΣCVCT

The QR-code watermark Q is decomposed in the same way:

Q = UQΣQVQT

The watermark is embedded by modifying the singular values of the cover image:

Σ̃ = ΣC + αΣQ

Here, α controls the watermark strength. The watermarked image is then reconstructed as:

Cα = UCΣ̃VCT

The process is applied independently to the three RGB channels.

SVD Implementation

Instead of directly calling numpy.linalg.svd, the SVD was implemented using eigendecomposition of the Gram matrix.

G = MMT

The eigenvalues of G are used to obtain the singular values:

σi = √λi

The corresponding eigenvectors are used to construct the singular-vector matrices required for reconstruction. Small singular values are handled separately to avoid numerical instability.

This makes the implementation useful for understanding the internal mechanics of SVD rather than treating it as a black-box operation.

Watermark Recovery

During recovery, the singular values of the watermarked image are used together with the original cover singular values to estimate the watermark singular values.

Σ̃Q = (Σ′ − ΣC) / α

The estimated singular values are then combined with the watermark's singular vectors to reconstruct the QR code.

Recovery is evaluated in two ways: PSNR measures numerical similarity, while QR decoding checks whether the recovered watermark is actually usable.

Baseline Results

The first experiment verifies the complete watermarking and recovery pipeline before introducing additional image degradation.

Effect of Watermark Strength

The watermark strength α is varied from 0.01 to 0.50. For each value, the image quality and recovered watermark quality are evaluated using PSNR.

α = 0.01 α → 0.50

Increasing α makes the watermark stronger but also introduces more distortion into the cover image. Recovery quality also varies with α, showing that the strongest watermark is not necessarily the best choice.

Robustness to Gaussian Noise

Gaussian noise is added to the watermarked images before attempting watermark recovery.

σ = 0.01 σ = 0.05 σ = 0.10 σ = 0.15

At lower noise levels, the watermark remains recoverable for the tested images. At higher noise levels, recovery quality drops significantly and QR decoding fails for the tested watermark strengths.

OBSERVATION

Increasing watermark strength alone cannot compensate for sufficiently strong noise.

Robustness to JPEG Compression

Watermarked images are compressed using different JPEG quality factors.

Quality = 90 Quality = 70 Quality = 50 Quality = 30

JPEG compression reduces the quality of the recovered watermark as compression becomes stronger.

For the tested images, watermark recovery was strongest around an intermediate watermark strength of approximately α ≈ 0.1–0.15.

Increasing α beyond this range does not continuously improve recovery because additional distortion and clipping can affect the result.

Key Findings

01

α controls the trade-off between watermark strength and cover-image distortion.

02

Very small α values preserve the cover image better but can be more sensitive to degradation.

03

Very large α values introduce more distortion and can cause clipping.

04

Gaussian noise has a strong effect on watermark recovery at higher noise levels.

05

JPEG compression increasingly degrades recovery as compression becomes stronger.

06

An intermediate α can provide a better balance between image quality and watermark recovery than simply maximizing watermark strength.

TAKEAWAY

The important part of the project was not simply embedding a QR code, but understanding how watermark strength, image quality, and robustness interact.

SVD-Based Image Watermarking and Robustness Analysis

Understanding how singular-value perturbations affect image quality and watermark robustness.

Harshada Kale · Computer Vision Project
View on GitHub →

How much information can be embedded into an image without significantly changing its appearance, and how much of that information can still be recovered after the image is degraded?

This project explores that question using Singular Value Decomposition (SVD). I built an image watermarking pipeline that embeds a QR-code watermark into a cover image by modifying its singular values, then evaluated how the watermark behaves under different embedding strengths and image degradations.

The Problem

A watermark needs to satisfy two competing requirements. It should be strong enough to survive changes to the image, but weak enough that the original image is not visibly distorted.

This creates a trade-off between imperceptibility and robustness. Rather than treating the watermarking algorithm as a black box, I used the project to understand how this trade-off emerges from the underlying linear algebra.

Why SVD?

An image can be represented as a matrix of pixel intensities. Singular Value Decomposition factorizes this matrix into three components:

A = UΣVT

Here, U and V contain the singular vectors, while Σ contains the singular values. The singular values provide a convenient representation in which the image can be modified in a controlled way.

This makes SVD useful for watermarking. Instead of modifying individual pixels directly, the watermark can be incorporated into the singular-value representation of the image.

The Approach

The complete pipeline consists of four main stages: decomposing the cover image and watermark, modifying the singular values, reconstructing the watermarked image, and finally estimating and reconstructing the watermark.

The important design choice is that the watermark is introduced in the singular-value domain rather than directly in pixel space. The parameter α controls how strongly the watermark affects the cover image.

Embedding the Watermark

Let the cover image be represented by C. Its singular value decomposition is:

C = UCΣCVCT

The QR-code watermark Q is decomposed in the same way:

Q = UQΣQVQT

The watermark is then introduced by modifying the singular values of the cover image:

Σ̃ = ΣC + αΣQ

The parameter α determines the embedding strength. A larger α makes the watermark contribution stronger, while also increasing the possibility of distortion in the reconstructed image.

The watermarked image is reconstructed using the original singular vectors of the cover image:

Cw = UCΣ̃VCT

For RGB images, the same operation is applied independently to the three color channels.

Understanding SVD from Eigendecomposition

Rather than treating SVD as a single library call, I also implemented the decomposition using eigendecomposition to understand the numerical relationship between the two methods.

For a matrix M, the Gram matrix can be constructed as:

G = MMT

The eigenvalues of G are related to the singular values of M:

σi = √λi

The corresponding eigenvectors provide the singular-vector basis. These components can then be combined to reconstruct the original matrix.

This implementation also exposed a practical numerical issue: very small eigenvalues can produce unstable results because numerical errors become more significant during the reconstruction. Handling these cases carefully was therefore part of the implementation.

Recovering the Watermark

After the watermarked image has been produced, the next question is whether the embedded information can be recovered.

Suppose Σ′ represents the singular values obtained from the watermarked image. Since the embedding operation was:

Σ̃ = ΣC + αΣQ

the watermark component can be estimated as:

Σ′Q = (Σ′ − ΣC) / α

The estimated singular values are then combined with the watermark's singular vectors to reconstruct the recovered watermark.

Recovery was evaluated in two ways. PSNR measures the numerical similarity of the recovered image, while QR decoding provides a more practical test: whether the recovered watermark still contains usable information.

Experiments

The main experimental variable was the watermark strength α. I varied α to study how the amount of embedded information affects image quality and recovery.

I then tested the watermarked images under different forms of degradation, including Gaussian noise and JPEG compression. These experiments help separate two questions: how much the watermark changes the original image, and how well that information survives after the image is modified.

1. Effect of Watermark Strength

When α is small, the modification to the cover image is small, which helps preserve visual quality. However, the watermark contribution is also weaker.

Increasing α strengthens the embedded signal, but this comes with a corresponding increase in image distortion. The useful operating point therefore lies between these two extremes.

2. Baseline Recovery

Before applying image degradation, the basic embedding and recovery pipeline was evaluated on the cover image. The recovered QR image provides a direct visual check of whether the embedded information can be reconstructed successfully.

3. Robustness to Gaussian Noise

Gaussian noise was introduced after watermark embedding to examine how reliably the embedded information survives random perturbations to the image.

Comparing different values of α makes it possible to observe how embedding strength affects recovery as the noise level increases.

4. Robustness to JPEG Compression

JPEG compression provides a different type of degradation because information is discarded during lossy compression. Different compression quality levels were applied before attempting watermark recovery.

This experiment tests whether the watermark remains useful when the image is stored or transmitted using a lossy format.

Results

The experiments show the expected trade-off between watermark strength, image quality, and robustness. Rather than simply maximizing α, the useful operating region depends on how much distortion can be tolerated and what type of degradation the watermark needs to survive.

Key Findings

  • Watermark strength creates a direct trade-off between image fidelity and robustness.
  • Increasing the embedding strength does not automatically produce better recovery under every type of degradation.
  • PSNR alone is not sufficient to evaluate watermark recovery; successful QR decoding provides a more task-oriented measure.
  • Implementing SVD through eigendecomposition highlighted numerical issues that are hidden when the decomposition is treated as a library primitive.

Implementation

The project was implemented using Python, NumPy, OpenCV, and Matplotlib. The main components include the SVD decomposition, watermark embedding and recovery pipeline, image degradation experiments, and quantitative evaluation.

Python · NumPy · OpenCV · Matplotlib · SVD · QR Decoding

Takeaway

The main takeaway from the project was that the behavior of an algorithm is easier to reason about when its underlying representation is understood.

Implementing the decomposition and then experimenting with the embedding parameter made the relationship between the mathematics, numerical behavior, and practical image quality much more explicit.

SVD-Based Image Watermarking and Robustness Analysis

Exploring how Singular Value Decomposition can be used to embed and recover a QR-code watermark while studying the trade-off between image quality and robustness.

Harshada Kale · Computer Vision Project
View source code on GitHub →

Digital watermarking is a technique for embedding information into an image while keeping the visual appearance of the image largely unchanged.

In this project, I implemented an image watermarking pipeline based on Singular Value Decomposition (SVD). A QR code containing a roll number is embedded into RGB cover images and later recovered from the watermarked image.

The main goal was not only to make the watermarking pipeline work, but to study an important question: how should the watermark strength be chosen so that the watermark remains recoverable without unnecessarily degrading the original image?

Why use SVD?

Singular Value Decomposition represents a matrix as the product of three matrices:

A = UΣVT

Here, the singular values in Σ describe the magnitude of different components of the matrix, while U and V contain the corresponding singular vectors.

This makes the singular values useful for watermarking. Instead of directly modifying image pixels, information can be embedded by modifying the singular values and then reconstructing the image.

The Watermarking Pipeline

The complete process can be summarized as follows:

01 Cover Image
→
02 SVD
→
03 Embed
→
04 Reconstruct
↓
05 Degradation
→
06 Recovery
→
07 QR Check

Embedding the Watermark

Let the cover image be represented by C. Its singular value decomposition is:

C = UCΣCVCT

The QR-code watermark Q is similarly decomposed:

Q = UQΣQVQT

The watermark is embedded by modifying the singular values of the cover image:

Σ̃ = ΣC + αΣQ

The parameter α controls the strength of the watermark. A larger α produces a stronger watermark, but also has the potential to introduce more distortion into the cover image.

The watermarked image is then reconstructed using the original singular vectors:

Cα = UCΣ̃VCT

The same procedure is applied independently to the three RGB channels.

Implementing SVD from Eigendecomposition

One part of the project was implementing SVD without directly relying on a library SVD routine.

For a matrix M, the Gram matrix can be constructed as:

G = MMT

The eigenvalues of this matrix are related to the singular values of M. Specifically:

σi = √λi

The eigenvectors are then used to construct the singular-vector matrices and reconstruct the original matrix.

This implementation also required handling small singular values carefully to avoid numerical instability.

Recovering the Watermark

After obtaining a watermarked image, the goal is to estimate the singular values of the embedded watermark.

If Σ′ represents the singular values obtained from the watermarked image, the watermark component can be estimated as:

Σ′Q = (Σ′ − ΣC) / α

The estimated watermark singular values are combined with the watermark singular vectors to reconstruct the recovered QR image.

Recovery is evaluated using two different ideas. PSNR measures numerical similarity, while QR decoding provides a more practical test of whether the recovered watermark is actually usable.

Baseline Results

Before testing robustness, the basic embedding and recovery pipeline was evaluated on the cover images.

Choosing the Watermark Strength

The watermark strength α was varied from 0.01 to 0.50 to study how it affects image quality and watermark recovery.

When α is very small, the watermark introduces little distortion, but it can also become more difficult to recover after image degradation.

Increasing α makes the watermark stronger. However, beyond a certain point, increasing the watermark strength does not necessarily improve recovery and can instead introduce additional distortion and clipping.

Robustness to Gaussian Noise

To test robustness, Gaussian noise was added to the watermarked images before attempting recovery.

Several noise levels were tested, including σ = 0.01, 0.05, 0.10, and 0.15.

At lower noise levels, the watermark remains more recoverable. As the noise becomes stronger, the recovered watermark quality decreases and QR decoding can eventually fail.

This experiment shows why simply increasing α is not enough to guarantee robustness against strong noise.

Robustness to JPEG Compression

The second robustness experiment studied the effect of JPEG compression. Watermarked images were compressed using different quality factors.

The tested quality factors included 90, 70, 50, and 30. Lower quality factors correspond to stronger compression.

For the tested images, recovery was strongest around an intermediate watermark strength of approximately α ≈ 0.1–0.15. Increasing α beyond this range does not continuously improve recovery because additional distortion and clipping can affect the result.

How the Results Were Evaluated

The experiments used several complementary measures rather than relying on a single metric.

Image quality. PSNR was used to measure the difference between the original cover image and its watermarked version.

Watermark recovery. PSNR was also used to compare the original watermark with the recovered watermark.

QR decoding. The recovered QR code was checked to determine whether the embedded information could actually be decoded.

What the Experiments Showed

The experiments highlight a clear trade-off between watermark strength and image quality. A very weak watermark preserves the cover image well, but can become sensitive to degradation.

On the other hand, a very strong watermark introduces greater distortion and can lead to clipping without providing a proportional improvement in recovery.

The robustness experiments also showed that the type and severity of degradation matter. Gaussian noise and JPEG compression affect the recovered watermark differently, so there is no single watermark strength that is automatically optimal for every situation.

This makes α an important design parameter rather than simply a value that should be maximized.

Takeaway

The main takeaway from the project is that image watermarking is a trade-off rather than a simple embedding problem.

SVD provides a useful way to control this trade-off through the singular values of the image. The experiments made it possible to see how watermark strength, image quality, noise, compression, and recovery interact.

Possible Extensions

Some natural extensions would be to compare this method with DCT- and DWT-based watermarking, test additional attacks such as cropping and filtering, and evaluate recovery using perceptual image-quality metrics in addition to PSNR.

SVD-Based Image Watermarking

An image watermarking system using Singular Value Decomposition to embed and recover a QR-code watermark, with experiments studying image quality and robustness under Gaussian noise and JPEG compression.

View on GitHub →

Overview

Digital watermarking allows information to be embedded into an image without placing an obvious visible mark on the image.

In this project, a QR code containing a roll number is embedded into RGB cover images using Singular Value Decomposition (SVD). The watermark strength is controlled by a parameter α, which allows the effect of watermark strength on image quality and recovery to be studied.

The main focus of the project is not only watermark embedding, but understanding the trade-off between image quality, watermark recoverability and robustness.

KEY QUESTION

How strong should the watermark be so that it remains recoverable without unnecessarily degrading the original image?

Method

For a cover image C, the image is decomposed using SVD:

C = UC ΣC VCT

The QR-code watermark Q is decomposed in the same way:

Q = UQ ΣQ VQT

The watermark is embedded by modifying the singular values of the cover image:

ΣW = ΣC + αΣQ

Here, α controls the watermark strength. The watermarked image is reconstructed using the original singular vectors of the cover image:

CW = UC ΣW VCT

The same process is applied independently to the three RGB channels.

SVD Implementation

Instead of directly using numpy.linalg.svd, the SVD was implemented using eigendecomposition of the Gram matrix.

G = MMT

The eigenvalues of the Gram matrix are used to obtain the singular values:

σi = √λi

The corresponding eigenvectors are then used to construct the singular-vector matrices needed for reconstruction. Small singular values are handled separately to avoid numerical instability.

This implementation was useful for understanding the internal mechanics of SVD rather than treating it as a black-box library operation.

Watermark Recovery

During recovery, the singular values of the watermarked image are used together with the original cover singular values to estimate the watermark singular values.

ΣQ = (ΣW − ΣC) / α

The recovered singular values are then combined with the watermark's singular vectors to reconstruct the QR code.

PSNR is used to measure numerical recovery quality, while QR decoding provides a practical check of whether the recovered watermark can actually be used.

Baseline Results

The first experiment evaluates the complete watermarking and recovery pipeline before introducing additional image degradation.

Effect of Watermark Strength

The watermark strength α was varied from 0.01 to 0.50. For each value, two quantities were evaluated:

Cover Image PSNR Measures distortion introduced by watermarking
Watermark PSNR Measures recovered watermark quality

Increasing α makes the watermark stronger but also introduces more distortion into the cover image. Recovery quality does not continuously improve with α, showing that the strongest watermark is not necessarily the best choice.

Robustness to Gaussian Noise

Gaussian noise was added to the watermarked images before attempting watermark recovery.

σ = 0.01 σ = 0.05 σ = 0.10 σ = 0.15

At lower noise levels, the watermark remained recoverable for the tested images. At higher noise levels, recovery quality dropped significantly and QR decoding failed for the tested watermark strengths.

OBSERVATION

Increasing watermark strength alone cannot compensate for sufficiently strong noise.

Robustness to JPEG Compression

Watermarked images were compressed using different JPEG quality factors:

Quality = 90 Quality = 70 Quality = 50 Quality = 30

Stronger JPEG compression reduces the quality of the recovered watermark. For the tested images, watermark recovery was strongest around an intermediate watermark strength of approximately α = 0.1–0.15.

Increasing α beyond this range does not continuously improve recovery because additional distortion and pixel clipping can negatively affect the result.

Key Findings

01

Increasing α strengthens the watermark but also increases distortion in the cover image.

02

Very small α values preserve image quality better but can be more sensitive to degradation.

03

Strong Gaussian noise significantly reduces watermark recovery quality.

04

Stronger JPEG compression makes watermark recovery more difficult.

05

The largest α is not necessarily the best choice; an intermediate value can provide a better balance between image quality and recovery.

TAKEAWAY

The important part of the project was not simply embedding a QR code, but understanding how watermark strength, image quality and robustness interact.

Future Improvements

  • Compare SVD watermarking with DCT- and DWT-based methods.
  • Test robustness against resizing, filtering and cropping.
  • Automate QR-decoding success rates across experiments.
  • Add perceptual image-quality metrics alongside PSNR.
  • Study the optimal α for different types and levels of image degradation.

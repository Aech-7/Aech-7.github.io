Dough Rolling Robot

Working on a Franka robot system for rolling dough to a consistent thickness. The system uses force sensing for controlling the rolling interaction and a camera to observe the dough surface, with ROS2 handling the robot-side software.

Warehouse Robot

Built a mobile robot for autonomous warehouse mapping and inventory tracking. The rover uses LiDAR and IMU data to build a map and navigate through the warehouse, while a camera detects and reads QR codes on racks and stores the inventory information.

ROS2 · SLAM · Gazebo · Autonomous Navigation · Computer Vision

Humanoid Supervisor Robot

Built a humanoid robot that can listen to spoken commands and use a locally running LLaMA model to decide which robot actions to perform. An agentic tool-calling system connects the language model to servo-controlled head, eye, and jaw movements.

LLaMA 3.1 · Tool Calling · Speech Processing · Servo Control. Rubik Pi

Quadcopter Modelling & Control

Built a six-DOF mathematical model of a quadcopter, including its dynamics, motor behavior, and aerodynamic effects. Used it to simulate attitude-rate and altitude control in MATLAB/Simulink.

MATLAB/Simulink · Quadrotor Dynamics · PID Control · Euler–Lagrange
